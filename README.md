# Student Performance Data Analysis

## Project Description

This project focuses on cleaning and analyzing student performance data using Microsoft Excel. The dataset was checked for duplicate records, summarized, and visualized using charts.

## Features

* Total Students Count
* Male Students Count
* Female Students Count
* Average Age Calculation
* Duplicate Record Detection
* Gender Distribution Pie Chart

## Tools Used

* Microsoft Excel

## How to Run

1. Open the Excel file.
2. Go to the Analysis sheet.
3. View the summary statistics and pie chart.

## Output

The project provides:

* Cleaned dataset
* Student statistics summary
* Gender distribution visualization
